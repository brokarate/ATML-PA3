Advanced Topics in Machine Learning, Fall 2026.

## Status

Repository setup in progress. Experiments have not been implemented or run.
The assignment specification is in `ATML-PA3.pdf`.

## Tasks

1. Fine-tune Qwen3-0.6B on mathematics using Full FT, Full FT + L2-SP,
   LoRA-4, LoRA-16, and OPLoRA-16; evaluate adaptation and retention.
2. Train a SigLIP–Qwen vision-language model through caption alignment,
   visual instruction tuning, and natural VQA specialization; evaluate grounding.
3. Analyze supplied LLM/VLM rollouts, compare live inference strategies,
   and evaluate adaptive sampling.
